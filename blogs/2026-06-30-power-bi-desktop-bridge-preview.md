Power BI Desktop Bridge (Preview) Power BI Desktop Bridge introduces a new way of working, allowing external applications and agents to interact directly with Power BI Desktop! What is Power BI Desktop Bridge? The bridge is a lightweight local server that lets external applications interact directly with Power BI Desktop.
